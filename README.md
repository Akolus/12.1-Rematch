Unofficial compatibility fixes and quality-of-life improvements integrated directly into Rematch.

Features
Target detection fixes: Restores supported NPC identification and saved-team popups when WoW restricts target information.
Enemy Ability Bar: Shows all three active enemy abilities with native tooltips, damage, hit chance, and pet-family effectiveness.
Enemy cooldown tracking: Tracks cooldowns round-by-round, preserving each enemy pet’s history through swaps.
Customizable icons: Adjust size, spacing, cooldown font, and text position directly in Rematch Options.
Optional battle UI: Compact panel with abilities, Battle Data, Pass, Autobattle, XP, and an integrated PvP timer. Blizzard’s UI remains the default; enable the custom version in Options.
Movable panel: Left-drag the custom panel’s top edge to reposition it. Position is saved.
Adjustable scale: Ctrl + mouse wheel over the custom panel.
Autobattle hotkey: Defaults to A, with support for custom keybinds. Existing saved bindings are preserved.
Requirements

WoW Retail 12.1 and Rematch 5.3.1. Autobattle scripting requires Pet Battle Scripts.

Installation Note

Addon-manager updates may overwrite these modifications. Back up your files or reapply the modified version after updating.
